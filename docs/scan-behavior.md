# 扫描行为

首次扫描记录路径、大小、mtime 纳秒、创建时间（平台支持时）、inode 与 device ID。默认跳过 `.Spotlight-V100`、`.Trashes`、`.fseventsd`、隔离目录和卷标记文件；符号链接不跟随。

再次扫描时，路径、大小、mtime、inode 与 device ID 都匹配才复用哈希。任意不同都会清空该路径当前内容关联并留下 `content_changed` 事件，等待重新计算。

抽样算法为 `blake3-sample-v1`：小文件完整读取；大文件读取头、中、尾固定区间。抽样相同只是候选条件。完整哈希是流式 BLAKE3，内存不随文件大小增长。

Ctrl+C 会将当前 `scan_runs` 标记为 `interrupted`；此前逐文件提交的数据保留。`--resume` 通过持久化元数据执行幂等增量恢复，而非依赖脆弱的遍历栈。只有无遍历错误的完整扫描才标记缺失。卷路径不存在时更新卷为离线，不改写该卷历史副本。

Unix 上数据库路径字段使用原始字节 BLOB；测试会在允许非法 UTF-8 名称的文件系统上创建该类路径。macOS APFS 会在创建阶段拒绝非法字节（`EILSEQ`），该平台仍以系统可表示的路径字节保存名称，并覆盖 Unicode 规范化场景。
